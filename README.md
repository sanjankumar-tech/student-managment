# 🎓 Student Management System

A Full Stack Student Management System built using:

## Backend
- FastAPI
- SQLAlchemy
- PostgreSQL

## Frontend
- React
- Vite
- Axios

## Features

- Add Student
- View Students
- Update Student
- Delete Student
- Search Student
- REST API
- Swagger Documentation
